# VidCompress (vc) برای Termux

ابزاری تعاملی برای **فشرده‌سازی ویدیو در ترموکس** با FFmpeg؛ همراه با امکاناتی برای مدیریت زیرنویس، استخراج فریم، تعمیر فایل و بررسی تنظیمات مناسب گوشی.

## نصب

در Termux دستور زیر را اجرا کنید. نصب‌کننده در صورت نیاز `ffmpeg` و `curl` را نصب می‌کند و دستور `vc` را در دسترس قرار می‌دهد:

```bash
curl -fsSL https://raw.githubusercontent.com/Alireza123456w6w/V.C.-a-video-compresser-for-termux/main/install.sh | bash
```

برای دسترسی به ویدیوهای حافظهٔ مشترک گوشی، مجوز ذخیره‌سازی را هم فعال کنید:

```bash
termux-setup-storage
```

سپس Termux را دوباره باز کنید و ابزار را اجرا کنید:

```bash
vc
```

در منوی تعاملی می‌توانید ویدیوها را انتخاب کنید، صف بسازید، preset و تنظیمات را تغییر دهید و فشرده‌سازی را شروع کنید. برای دیدن راهنمای گزینه‌های خط فرمان:

```bash
vc --help
```

## امکانات

- انتخاب ویدیو از حافظهٔ گوشی، جست‌وجو، مرور پوشه‌ها و صف چندفایلی
- presetهای آماده مانند `balanced`، `quality`، `small`، `social` و `turbo`
- انتخاب کدک‌های H.265، H.264 و AV1 (در صورت پشتیبانی نسخهٔ FFmpeg)
- تنظیم کیفیت، وضوح، نرخ فریم، صدا، پوشهٔ خروجی و زیرنویس
- ابزار زیرنویس برای افزودن، سوزاندن، استخراج یا حذف زیرنویس
- تعمیر و بررسی مشکلات همگام‌سازی صدا و تصویر و سازگاری با تلویزیون
- ساخت GIF، استخراج صدا، تصویر بندانگشتی، برگهٔ تماس و استخراج فریم‌ها
- آزمایش سرعت presetها و تنظیمات CPU روی دستگاه

## چند نمونهٔ کاربردی

فشرده‌سازی تعاملی:

```bash
vc
```

فشرده‌سازی با preset متعادل، بدون ورود به منو:

```bash
vc -y -p balanced /sdcard/Movies/video.mp4
```

هدف‌گذاری حجم تقریبی ۹۵ مگابایت:

```bash
vc -y -p target -t 95 /sdcard/Movies/video.mp4
```

بررسی مشکل همگام‌سازی یا تعمیر ویدیو:

```bash
vc --diagnose /sdcard/Movies/video.mp4
vc --repair /sdcard/Movies/video.mp4
```

استخراج فریم‌های بین ثانیهٔ ۹۰ تا ۱۰۰:

```bash
vc --frames /sdcard/Movies/video.mp4 -S 90 -E 100
```

## حذف

برای حذف دستورهای نصب‌شده اجرا کنید:

```bash
vcdel
```

این دستور فایل‌های اجرایی `vc` و `vcdel` را حذف می‌کند؛ تنظیمات ذخیره‌شده در پوشهٔ `$HOME/.config/vidcompress` را پاک نمی‌کند.

## پیش‌نیاز و نکته

این ابزار برای **Termux** طراحی شده و به `bash`، `ffmpeg` و `ffprobe` نیاز دارد. بعضی قابلیت‌ها مثل AV1 و کدگذاری سخت‌افزاری به encoderهای موجود در نسخهٔ FFmpeg دستگاه وابسته‌اند. برای فایل‌های مهم، نسخهٔ اصلی را تا زمان بررسی خروجی نگه دارید.
